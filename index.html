Konfigurasi Cloud & Sinkronisasi Real-Time

Hubungkan E-Bendahara ke Firebase Realtime Database (100% Gratis dari Google) agar seluruh data kas, matriks, buku kas, dan pinjaman otomatis sinkron secara real-time di seluruh HP dan laptop pengurus tanpa mengulang dari awal saat berganti perangkat.

Status Koneksi: Mode Offline (Lokal)

Atau Isi Parameter Secara Manual:

Panduan 2 Menit Membuat Firebase Realtime Database (Gratis Selamanya)

1. Buka console.firebase.google.com dan login dengan akun Google Anda.

2. Klik "Add project", beri nama misalnya e-bendahara (lewati Google Analytics).

3. Di menu sebelah kiri, buka Build ➔ Realtime Database, lalu klik Create Database (pilih lokasi Singapore / asia-southeast1 atau United States).

4. Pada tab Rules di Realtime Database, ubah menjadi:

{
  "rules": {
    ".read": true,
    ".write": true
  }
}

Lalu klik Publish.

5. Klik ikon gerigi (Project Settings) di pojok kiri atas ➔ gulir ke bawah ➔ klik ikon Web (</>) ➔ salin isi const firebaseConfig = { ... } lalu tempelkan pada kolom di atas!
